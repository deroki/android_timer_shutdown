Key Features

Engineered for high reliability, zero bloat, and battery conservation

100% Standalone (No Root)

Uses an automated Accessibility Service to open the system power menu and power down cleanly. No computer, Shizuku, or companion app needed.

Superuser Root Acceleration

Automatically detects root access. If your device is rooted, it triggers instant hardware power-off via superuser shell command.

Doze-Proof AlarmManager

Schedules exact alarms with setExactAndAllowWhileIdle to guarantee wakeup and shutdown even when Android is in deep battery saver Doze mode.

Automatic Reset on Screen On

Picking up and turning on the screen immediately cancels the shutdown timer, ensuring seamless everyday usability without interruption.

OEM Security Advisor

Built-in intelligence to detect manufacturer-specific lock screen PIN restrictions on Samsung One UI and Xiaomi MIUI/HyperOS.

Auto-Start on Boot

Restores screen idle monitoring automatically after device reboot via RECEIVE_BOOT_COMPLETED.
